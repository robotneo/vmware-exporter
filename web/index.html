参考文档

单目标模式

启动导出器时指定目标及凭证，然后让 Prometheus 抓取 /metrics：

./vmware-exporter \
  -vmware.vcenter=vcenter.example.com \
  -vmware.username=admin@vsphere.local \
  -vmware.password=secret \
  -vmware.insecureTLS=true

同样的参数也适用于独立 ESXi 主机。无需选择模式：导出器在登录时读取 ServiceContent.About.ApiType 自动适配，因为独立主机没有实际的数据中心或集群对象可遍历。

命令行上的密码是可见的，任何能运行 ps 或读取 /proc 的人都能看到。建议使用 -envflag.enable 配合环境变量文件。
时间参数
参数默认值作用
-vmware.timeout60一次抓取的总超时（秒），涵盖登录、属性检索和性能采样。清单较大时可适当调高。
-vmware.interval20PerfManager 采样窗口（秒），与抓取超时相互独立。
-vmware.granularity20采样频率（秒），必须大于 0 且不超过 interval。
多目标模式

必填参数：target、username、password。可选：schema（默认 https）、insecure=true（跳过 TLS 验证）。

凭证也可以通过 HTTP Basic Auth 传递，而非 URL 参数。

Basic Auth 与 -web.config.file 冲突。当导出器自身监听器配置了 basic_auth_users 时，Authorization 头被其自身占用，vCenter 凭证无法通过此方式传递。请使用 URL 参数，或调试控制台（通过表单体提交）。

采集器通过可重复的 collect[] 和 nocollect[] 参数选择：

# 仅默认采集器
/probe?target=vcenter.example.com&username=admin&password=secret&insecure=true

# 仅虚拟机和主机指标
/probe?target=...&collect[]=vm&collect[]=host

# 全部采集器
/probe?target=...&collect[]=all

# 全部，但排除 esxcli 采集器
/probe?target=...&collect[]=all&nocollect[]=esxcli.host.nic&nocollect[]=esxcli.storage

拼写错误的采集器名称将被拒绝并返回 HTTP 400 及有效名称列表，不会静默产生空指标集。

不同 vCenter 使用不同采集器，凭证通过服务发现文件而非 scrape config 携带：

scrape_configs:
  # 生产 vCenter —— 全部采集器
  - job_name: 'vmware-prod'
    scrape_interval: 60s
    metrics_path: /probe
    file_sd_configs:
      - files: ['/etc/prometheus/targets/vmware_prod.yml']
    params:
      schema: ['https']
      insecure: ['true']
      collect[]: ['all']
    relabel_configs:
      - source_labels: [__meta_username]
        target_label: __param_username
      - source_labels: [__meta_password]
        target_label: __param_password
      - source_labels: [__address__]
        target_label: __param_target
      - source_labels: [__param_target]
        target_label: instance
      - target_label: __address__
        replacement: localhost:9169

  # 开发 vCenter —— 仅基础采集器，抓取频率更低
  - job_name: 'vmware-dev'
    scrape_interval: 120s
    metrics_path: /probe
    file_sd_configs:
      - files: ['/etc/prometheus/targets/vmware_dev.yml']
    params:
      schema: ['https']
      insecure: ['true']
      collect[]: ['datacenter', 'host', 'vm']
    relabel_configs:
      - source_labels: [__meta_username]
        target_label: __param_username
      - source_labels: [__meta_password]
        target_label: __param_password
      - source_labels: [__address__]
        target_label: __param_target
      - source_labels: [__param_target]
        target_label: instance
      - target_label: __address__
        replacement: localhost:9169
